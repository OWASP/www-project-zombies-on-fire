# Tabletop game templates

Copy the [tabletop game template](tabletop-game.md) to design an exercise or adapt one of the Outbreaks below for a facilitated discussion. Use each round’s Signals as injects. Share the opening brief and participant instructions before play, then reveal Signals as their rounds begin. Keep the scenario truth, expected actions, and scoring notes with the facilitator.

## Built-in Outbreaks

The [browser game](../../games/zombies-on-fire/zombies-on-fire.html) contains the original scenario briefs, Signals, and debrief prompts.

- **First Shift** (3 rounds) introduces incident declaration, investigation, containment, and recovery.
- **Second Shift** (4 rounds) covers early decisions in a ransomware incident and introduces advanced game rules.
- **Patient Zero Chat** (6 rounds) follows an incident involving an AI shopping assistant.
- **Poisoned Well** (6 rounds) exercises response to a compromised software update.
- **Every Door Open** (6 rounds) covers response to a reported authorization flaw and potential data exposure.
- **The Session That Wouldn't Die** (6 rounds) explores containment and investigation of a compromised session.
- **Ashes** (6 rounds) tests ransomware recovery when backups are unavailable.
- **The Ghost Vendor** (6 rounds) covers a third-party checkout script incident and vendor coordination.
- **Keys in the Open** (4 rounds) tests response to a publicly exposed cloud credential.
- **Wire at Five** (4 rounds) exercises response to a fraudulent payment request.

For generated materials, enter the four exercise questions into the [authoring portal](../../portal/README.md). Its [document agents](../../portal/app/agents/) define the six formats used by the template.
